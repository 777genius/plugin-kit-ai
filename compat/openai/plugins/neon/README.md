# Neon

Community package for the official Neon hosted MCP plugin for database, branch, and project workflows through Neon's remote MCP server.

<!-- agentplugins-install:start -->
## Install

```bash
npx universal-agent-plugins@0.1.2 add neon
```
<!-- agentplugins-install:end -->

This is an independent community package for [Agent Plugins 1.0](https://agent-plugins.org/specification). It is not an endorsement or an official package from Neon.

- Component: MCP server
- Transport: `streamable-http`
- Upstream documentation: https://mcp.neon.tech/
- Authentication: Authentication is discovered and managed by the client. No credentials are bundled.

Review the server's tools, scopes, and write capabilities before enabling it. Agent Plugins 1.0 standardizes packaging, not permissions or sandboxing.
