# Linear

Community package for the official Linear MCP integration for workspace management, issues, and project workflows.

<!-- agentplugins-install:start -->
## Install

```bash
npx --yes universal-agent-plugins@0.1.1 add linear
```
<!-- agentplugins-install:end -->

This is an independent community package for [Agent Plugins 1.0](https://agent-plugins.org/specification). It is not an endorsement or an official package from Linear.

- Component: MCP server
- Transport: `streamable-http`
- Upstream documentation: https://linear.app
- Authentication: Authentication is discovered and managed by the client. No credentials are bundled.

Review the server's tools, scopes, and write capabilities before enabling it. Agent Plugins 1.0 standardizes packaging, not permissions or sandboxing.
